# AI Cheating Detection System

This project detects suspicious exam behavior using computer vision.

## Features
- Person detection using YOLOv8
- Face landmark tracking using MediaPipe
- Head direction detection
- Phone detection
- Multiple person detection
- Screenshot capture on suspicious activity
- 5-second cooldown between captures

## Tech Stack
- Python
- OpenCV
- YOLOv8
- MediaPipe

## Run
```bash
pip install -r requirements.txt
python main.py
